# 구해줘 독도! (Save Dokdo!)

정령과 독도 친구들을 구하며 독도의 역사와 자연을 배우는 **4, 5학년 독도 교육 게임**입니다.
Unity로 만든 원작을 웹 브라우저에서 바로 플레이할 수 있게 JavaScript로 다시 만들었습니다.
원작의 그림, 음악, 대사, 퀴즈, 스테이지 지형을 그대로 옮겨 왔어요.

**▶ 웹에서 플레이:** _(Vercel 주소가 생기면 여기에 적기)_

## 게임 구성

| 화면 | 내용 |
|---|---|
| 독도 마을 | 독도 석상(기억 퍼즐), 정령 구출, 독도 캐릭터 카드, 독도 생물 카드, 독도 아저씨 도움말 |
| 생물 카드 뒤집기 | 이지·노멀·하드 모드, 40초 안에 같은 카드 찾기 → 카드 점수(하트) |
| 달리고 구하고 풀어라! | 10개 스테이지. 열쇠로 힌트를 얻고, 정령을 구하고, 독도아저씨의 문제를 풀어 다음 스테이지로 |
| 파란 로봇 퀴즈 | 스테이지 곳곳의 파란 로봇 문제 23개. 처음 맞히면 독도 포인트 +5, 생물 카드 획득 |
| 독도를 건 마지막 승부 | 정령 10명을 모두 구하면 로보킹과 퀴즈 배틀 (독도 도서관 힌트 5번) |

## 조작법

| | PC | 휴대폰·태블릿 |
|---|---|---|
| 이동 | ← → 또는 A D | 화면 왼쪽 아래 ◀ ▶ |
| 점프 | Space, ↑ 또는 W | 화면 오른쪽 아래 점프 |
| 선택 | 마우스 클릭 | 터치 |

휴대폰은 가로로 돌려서 플레이하세요. 진행 상황은 브라우저에 자동 저장됩니다(같은 기기·같은 브라우저).

## 폴더 구조

```
web/                      Vercel이 그대로 보여 주는 웹사이트
  index.html              시작 페이지
  game/                   게임 코드 (빌드 과정 없음)
    core.js               화면·입력·소리·저장·UI 공통 기능
    story.js              인트로·이사부 장군·엔딩 대사
    hub.js                시작 화면, 독도 마을, 게임 선택
    cards.js              생물 카드 뒤집기
    stage.js              달리기 스테이지, 파란 로봇 퀴즈
    final.js              로보킹 퀴즈 배틀
    data/gamedata.json    Unity 프로젝트에서 뽑아낸 스테이지·퀴즈·대사 데이터
  assets/                 그림, 음악(96kbps로 줄임), 글꼴
```

### 글이나 문제를 고치고 싶을 때
- 스테이지 문제·힌트, 파란 로봇 문제, 마지막 승부 문제, 정령·영웅 이야기: `web/game/data/gamedata.json`
- 인트로·엔딩 대사: `web/game/story.js`

고친 뒤 GitHub에 올리면 Vercel이 1~2분 안에 자동으로 새 버전을 배포합니다.

### 내 컴퓨터에서 실행
`index.html`을 더블클릭하면 브라우저 보안 때문에 열리지 않아요. `web` 폴더에서 다음을 실행한 뒤 http://localhost:8000 을 여세요.

    python -m http.server 8000

## 원작과 달라진 점
- 9스테이지 로보킹 문제(조선시대 기록 중 독도가 우리 땅임을 나타내는 것)는 원작 연결에서 '시마네현 고시'가 정답으로 되어 있었으나, 힌트와 사실에 맞게 **세종실록**을 정답으로 고쳤습니다.
- '대한제국 칙령 41조'로 적힌 곳은 정식 명칭인 **대한제국 칙령 제41호**로 통일했습니다.
- 스테이지에서 정령을 구하면 구출 포인트를 그 정령을 마을에 불러낼 수 있을 만큼(1, 2, 4, …) 받습니다.
- 파란 로봇 문제를 맞힌 뒤에는 스테이지 처음으로 돌아가지 않고 그 자리에서 이어 합니다.
- '게임이 힘들어요!' 창에서 열쇠·정령·독도아저씨를 누르면 그곳으로 이동할 수 있습니다.
