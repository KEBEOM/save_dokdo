# 구해줘 독도! (Save Dokdo!)

정령과 독도 친구들을 구하며 독도의 역사와 자연을 배우는 **독도 교육 게임**입니다.
Unity로 만든 원작을 웹 브라우저에서 바로 플레이할 수 있게 JavaScript로 다시 만들었습니다.
원작의 그림, 음악, 대사, 퀴즈, 스테이지 지형을 그대로 옮겨 왔어요.

**▶ 웹에서 플레이:** _(Vercel 주소가 생기면 여기에 적기)_

## 게임 구성

| 화면 | 내용 |
|---|---|
| 독도 마을 | 독도 석상(기억 퍼즐), 정령 구출, 독도 캐릭터 카드, 독도 생물 카드, 독도 아저씨 도움말 |
| 생물 카드 뒤집기 | 이지·노멀·하드 모드, 40초 안에 같은 카드 찾기 → 카드 점수(하트) |
| 달리고 구하고 풀어라! | 10개 스테이지. 열쇠로 힌트를 얻고, 정령을 구하고, 독도아저씨의 문제를 풀어 다음 스테이지로 |
| 파란 로봇 퀴즈 | 스테이지 곳곳의 파란 로봇 문제 23개. 처음 맞히면 독도 포인트 +5, 생물 카드 획득 |
| 독도를 건 마지막 승부 | 정령 10명을 모두 구하면 로보킹과 퀴즈 배틀 (독도 도서관 힌트 5번) |

## 조작법

| | PC | 휴대폰·태블릿 |
|---|---|---|
| 이동 | ← → 또는 A D | 화면 왼쪽 아래 ◀ ▶ |
| 점프 | Space, ↑ 또는 W (공중에서 한 번 더: 더블 점프) | 화면 오른쪽 아래 점프 (공중에서 한 번 더: 더블 점프) |
| 선택 | 마우스 클릭 | 터치 |

휴대폰은 가로로 돌려서 플레이하세요. 진행 상황은 브라우저에 자동 저장됩니다(같은 기기·같은 브라우저).

## 폴더 구조

```
web/                      Vercel이 그대로 보여 주는 웹사이트
  index.html              시작 페이지
  game/                   게임 코드 (빌드 과정 없음)
    core.js               화면·입력·소리·저장·UI 공통 기능
    story.js              인트로·이사부 장군·엔딩 대사
    hub.js                시작 화면, 독도 마을, 게임 선택
    cards.js              생물 카드 뒤집기
    stage.js              달리기 스테이지, 파란 로봇 퀴즈
    final.js              로보킹 퀴즈 배틀
    data/gamedata.json    Unity 프로젝트에서 뽑아낸 스테이지·퀴즈·대사 데이터
  assets/                 그림, 음악(96kbps로 줄임), 글꼴
```

### 글이나 문제를 고치고 싶을 때
- 스테이지 문제·힌트, 파란 로봇 문제, 마지막 승부 문제, 정령·영웅 이야기: `web/game/data/gamedata.json`
- 인트로·엔딩 대사: `web/game/story.js`

고친 뒤 GitHub에 올리면 Vercel이 1~2분 안에 자동으로 새 버전을 배포합니다.

### 내 컴퓨터에서 실행
`index.html`을 더블클릭하면 브라우저 보안 때문에 열리지 않아요. `web` 폴더에서 다음을 실행한 뒤 http://localhost:8000 을 여세요.

    python -m http.server 8000

## 원작과 달라진 점
- **포인트 통일**: 원작의 독도 포인트·카드 점수(하트)·구출 포인트를 **독도 포인트 하나**로 합쳤습니다.

  | 얻기 | 독도 포인트 |
  |---|---|
  | 동전 | +3 |
  | 파란 로봇 문제 (처음 맞힐 때) | +5 |
  | 스테이지에서 정령 구출 | +10 |
  | 카드 뒤집기 (짝 하나당 이지/노멀/하드) | 2 / 5 / 10 |

  | 쓰기 | 독도 포인트 |
  |---|---|
  | 정령 퍼즐 (스테이지를 깨야 열림) | 20 |
  | 영웅 퍼즐 1~5 | 30 / 50 / 80 / 120 / 150 |
  | 마을에 정령 불러내기 1~10 | 10, 20, … 100 |
  | 캐릭터·생물 카드 | 30부터 한 장 살 때마다 10씩 오름 |
- **랜덤 맵**: 스테이지에 들어갈 때마다 맵이 새로 만들어집니다(`web/game/levelgen.js`). 맵은 여러 구역을 이어 붙여 위아래로 오르내립니다.
  - 오르락내리락 달리기, 지그재그 탑 오르기, 아래로 뚝 떨어지는 낭떠러지 (1스테이지부터)
  - 위로 올라가는 엘리베이터 발판 (2스테이지부터), 옆으로 움직이는 나룻배 발판 (3스테이지부터), 좁은 기둥 건너기 (4스테이지부터). 움직이는 발판은 노란 테두리와 점선 길로 표시됩니다.
  - 예전 랜덤 맵보다 약 2배 어렵습니다: 구역 수(5~14개), 발판 수, 높이 차, 간격이 늘고 발판이 좁아지며, 빨간 로봇은 약 2배 많고 빠릅니다. 발판은 항상 (더블) 점프로 닿을 수 있는 거리 안에서만 만들어집니다.
  - 파란 로봇은 가끔 폴짝 뛰어오르고, 스테이지가 오를수록 더 자주, 더 높이 뜁니다. 파란 로봇 문제·힌트·정령은 원작 스테이지 그대로입니다.
  - 서 있던 곳보다 16칸 넘게 떨어지면 체크포인트로 돌아갑니다.
- 독도아저씨(9~10스테이지는 로보킹)는 항상 주인공이 있는 쪽을 바라봅니다.
- 9스테이지에서 로보킹을 만나면 원작 대사("오호..너는 누구냐..", "나는 로봇들의 왕 로보킹이다.", "너의 실력을 확인해볼 겸 문제를 내보겠다.") 뒤에 문제가 나옵니다.
- 파란 로봇 문제를 맞히거나 마을에서 카드를 사면 카드 뒷면이 먼저 나오고, 눌러야 뒤집히며 어떤 카드인지 나옵니다.
- 열쇠 3개와 정령은 서로 다른 발판에 3칸 넘게 떨어져 놓입니다.
- 맵의 물건끼리 겹치지 않습니다: 한 발판에 로봇은 하나만, 독도 포인트는 지형·로봇·열쇠·정령·문·다른 포인트와 겹치는 자리에는 놓지 않습니다. 열쇠·정령은 지형에 박히지 않게 놓이고, 그 발판에는 로봇을 두지 않습니다. 문제를 내는 파란 로봇이 먼저 자리를 잡아 원작 문제가 빠짐없이 나옵니다.
- 파란 로봇이 예전보다 약 2배 자주 뜁니다.
- 파란 로봇 문제를 맞히면 매번 보상을 하나 줍니다: 독도 포인트 +10(70%) 또는 아직 없는 생물 카드 한 장(30%). 생물 카드를 다 모았으면 항상 독도 포인트입니다. 뒷면 카드를 눌러 뒤집어야 무엇이 나왔는지 보입니다. 이미 맞힌 문제 로봇도 스테이지에 다시 들어오면 또 문제를 냅니다. 같은 판 안에서 맞힌 로봇만 흐리게 바뀝니다.
- 초록 로봇(2스테이지부터, 스테이지가 오를수록 많아짐): 걸어 다니다가 주인공이 가까이 오면 멈춰서 둥그렇게 구긴 종이 뭉치를 던집니다. 종이 뭉치에 맞으면 날아온 쪽 반대로 튕겨 나가고(체크포인트로 돌아가지는 않음, 0.7초 동안은 다시 맞지 않음), 초록 로봇 몸에 닿으면 체크포인트로 돌아갑니다.
- 정령 몸짓: 원작의 Idle·Walk·Touch 애니메이션(크기 늘였다 줄이기)을 그대로 옮겼습니다. 마을 정령은 가만히 있을 때 2초마다 살짝 납작해지고, 걸을 때 통통 튀고, 누르면 쭉 늘어났다 눌립니다. 스테이지와 정령 구출 창의 정령도 같은 몸짓을 합니다. 마을 정령들은 서로 겹치지 않게 비켜서고, 양옆 버튼 앞으로는 가지 않습니다.
- 원작의 '게임이 힘들어요!'(열쇠·정령·독도아저씨 앞으로 순간 이동) 버튼과 시작 화면의 '4, 5학년 독도 교육' 문구는 뺐습니다.
- 날씨: 2스테이지부터 들어갈 때마다 맑음·비·눈 중 하나가 나옵니다(그림 효과만 있고 조작은 같습니다).
- 아래 방향키(↓, S)나 폰의 ▼ 버튼을 누르고 있으면 6칸 아래까지 내려다볼 수 있습니다.
- 마을 정령들이 걸어가는 방향을 바라봅니다.
- 이야기 장면에서 말하는 인물(독도아저씨·이사부 장군)은 오른쪽에 서서 아랫몸이 대화창 안으로 들어오고, 대사는 인물을 뺀 창 안의 빈 곳 한가운데에 나옵니다. 그림 옆에 글이 있는 창(열쇠 힌트, 독도아저씨·로보킹 대사, 파란 로봇 대사)도 글이 그림을 뺀 빈 곳 한가운데에 오도록 맞췄습니다.
- 9스테이지 문제 로봇 하나가 원작에서 문제 이름이 'Q23_Stage8'로 잘못 적혀 있어 퀴즈 화면이 멈추던 것을 'Q23_Stage9'로 고쳤습니다. 이름이 어긋나도 문제 번호로 찾아가고, 그래도 없으면 스테이지로 돌아갑니다.
- 마을로 정령을 데려오려면(정령 구출 창) 먼저 그 정령을 달리기 스테이지에서 구출해야 합니다.
- 카드·퍼즐 읽기 창: 위에 작은 분류와 큰 이름, 사진은 내용 칸의 세로 가운데, 캐릭터 대사는 파란 글씨로 따로 보여 줍니다. 짧은 설명은 사진 오른쪽 빈 곳의 가로·세로 한가운데에, 긴 글은 위에서부터 넘겨 읽습니다.
- 아직 얻지 못한 열쇠·정령은 원작처럼 같은 그림을 검정으로 칠한 그림자로 보입니다(스테이지 위쪽 칸, 정령 구출 창, 이야기의 ??? 인물). 캔버스 필터 대신 미리 칠한 그림자를 써서 아이폰 사파리에서도 똑같이 보입니다.
- 폰에서 화면을 꾹 눌러도 글자 선택·복사 메뉴가 뜨지 않습니다.
- 독도 석상의 정령·영웅 퍼즐은 원작 장면의 위치대로 조각을 맞춘 큰 그림으로 보여 줍니다(열린 조각은 색, 닫힌 조각은 흑백). 오른쪽 목록이나 그림 조각을 눌러 열어요. 조각 그림은 원작 장면 좌표로 미리 맞춰 `web/assets/img/spz_*`, `hpz_*`, `web/game/data/puzzles.json`에 들어 있습니다.
- 화면 배치를 다시 정리했습니다: 게임 방법 안내, 스테이지 문제, 정령 구출 화면, 정령 구출(마을) 창, 도움말, 카드 뒤집기 모드 선택·게임, 마지막 승부 문제 화면에서 글자·그림·버튼이 겹치지 않게 했습니다.
- 열쇠를 먹은 자리가 중간 저장 지점이 되어, 떨어지거나 로봇에 닿으면 그 자리에서 다시 시작합니다.
- 달리기 배경(`web/assets/img/runbg_*.png`): 스테이지가 오를수록 시간이 흐릅니다. 1~2스테이지 아침(`runbg_morning`), 3~5 한낮(`runbg_day`), 6~7 노을(`runbg_sunset`), 8~9 해질녘(`runbg_dusk`), 10 밤(`runbg_night`). 비·눈 오는 날은 `runbg_rain`, `runbg_snow`를 씁니다. 그림은 가로로 이어 붙여 천천히 흐르고, 카메라가 위로 올라가면 그림 맨 위 하늘색이 그대로 이어집니다. 해질녘·밤·노을에는 화면 전체를 살짝 물들여 발판과 인물도 배경과 어울리게 했습니다. 배경을 바꾸려면 같은 이름의 768×512 PNG로 덮어쓰면 됩니다.
- 9스테이지 로보킹 문제(조선시대 기록 중 독도가 우리 땅임을 나타내는 것)는 원작 연결에서 '시마네현 고시'가 정답으로 되어 있었으나, 힌트와 사실에 맞게 **세종실록**을 정답으로 고쳤습니다.
- '대한제국 칙령 41조'로 적힌 곳은 정식 명칭인 **대한제국 칙령 제41호**로 통일했습니다.
- 스테이지에서 정령을 구하면 구출 포인트를 그 정령을 마을에 불러낼 수 있을 만큼(1, 2, 4, …) 받습니다.
- 파란 로봇 문제를 맞힌 뒤에는 스테이지 처음으로 돌아가지 않고 그 자리에서 이어 합니다.
- 공중에서 점프를 한 번 더 할 수 있는 **더블 점프**를 넣었습니다.
- 맨 아래 바닥은 보이지 않게 했습니다. 떨어지면 처음 자리에서 다시 시작해요.
- 로봇이 아래로 떨어지면 원래 자리에 다시 나타납니다. 원작에서 발판 없는 허공·맵 밖에 놓였던 로봇 10마리는 가장 가까운 발판 위로 옮겼습니다.
- 배경음악: 메뉴 화면, 마을, 스테이지 1~3 / 4~6 / 7~8 / 9~10, 파란 로봇 퀴즈가 서로 다른 곡을 씁니다.
